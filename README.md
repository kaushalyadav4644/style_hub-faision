# StyleHub - Fashion Store

A modern, responsive e-commerce web application designed for browsing fashion trends, exploring categories, and shopping clothing, footwear, and accessories.

## 🚀 Features
* **Category Navigation:** Explore curated sections for Men's Fashion, Women's Fashion, Footwear, and Accessories.
* **Trending Products:** Showcase of popular items with direct pricing and an "Add to Cart" option.
* **Special Offers:** Highlight section featuring limited-time promotional discounts.
* **Responsive Design:** Fully optimized layout for seamless viewing across both mobile and desktop screens.

## 🛠️ Built With
* HTML5
* CSS3
* JavaScript
